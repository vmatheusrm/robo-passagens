Conectar o painel ao seu GitHub

Para o painel poder salvar filtros, ele precisa de uma chave de acesso ao repositório. A chave fica guardada só neste navegador. Faça isto uma vez em cada aparelho:
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Token name: painel-robo. Expiration: a maior opção disponível.
  3. Repository access: Only select repositories → robo-passagens.
  4. Permissions → Repository permissions: Contents = Read and write e Actions = Read and write.
  5. Clique em Generate token, copie e cole abaixo.
